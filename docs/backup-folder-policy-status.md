# 폴더 백업 정책 작업 현황

## 2026-08-31

- 관리자 백업 목록에서 폴더 행을 펼치거나 접을 수 있다.
- 펼친 폴더 안에서 하위 파일을 확인하고 파일별로 `포함` 또는 `제외` 예외 규칙을 지정할 수 있다.
- `폴더 전체 백업`과 `폴더 전체 제외`는 하위 파일 전체에 상속되며, 더 구체적인 파일 규칙이 우선한다.
- 스캔 중·백업 중·완료 상태에서도 최신 화이트리스트를 현재 목록에 다시 적용하고 백업을 시작할 수 있다.
- 스캔 응답 시각과 실제 백업 처리 시각을 분리해 진행 상태를 정확히 표시한다.
- TDD 검증: 백엔드 70건, 관리자 JavaScript 26건 및 관리자 프로덕션 빌드 통과.

## 관리자 사용 순서

1. 장치의 최신 인벤토리 실행을 선택한다.
2. 원하는 폴더에서 `폴더 전체 백업`을 누른다.
3. 폴더를 펼쳐 백업하지 않을 파일에는 `이 파일 제외`를 지정한다.
4. `발견 파일 백업 시작`, `백업 대상 다시 적용` 또는 `포함 목록 백업 시작`을 누른다.
5. 포함된 파일은 `Pending` 대기열에 들어가며 데스크톱 에이전트가 순서대로 업로드한다.
