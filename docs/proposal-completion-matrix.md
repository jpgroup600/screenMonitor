# 백업·보안 에이전트 제안서 구현 검증표

업데이트: 2026-08-31

이 문서는 `endpoint-backup-security-proposal.md`의 요구사항을 현재 코드와 실사용 검증 결과에 대조한다. `부분 구현`은 관련 코드가 있다는 뜻일 뿐 제안서 범위를 충족했다는 뜻이 아니다.

| 영역 | 상태 | 현재 증거 | 남은 작업 |
|---|---|---|---|
| Tauri 트레이·닫기 시 숨김·자동 시작 | 구현됨 | Tauri 창 이벤트, 트레이 메뉴, autostart 플러그인 및 설치본 실행 검증 | Windows 재부팅 실사용 검증 |
| Rust Windows 서비스 자동 시작 | 구현됨 | `ScreenMonitorAgent` 설치/교체 훅, LocalSystem·AUTO_START·RUNNING 실기기 검증 | 여러 PC 및 장시간 장애 복구 검증 |
| UI 종료 중 파일·USB·네트워크 감사 | 구현됨 | 서비스 수집기와 DPAPI 스풀, UI가 인증 후 서버 전송 | 서비스 자체 서버 인증이 없는 구조의 운영 지연 측정 |

| 브라우저 저장소 평문 인증정보 제거 | 구현됨 | 사용자 범위 DPAPI `auth-token.dat`, 기존 `localStorage` 자동 이전, JS/Rust TDD | 토큰 만료·강제 폐기 실사용 검증 |
| 모든 고정 드라이브 인벤토리 | 구현됨 | 고정 드라이브 탐색, 배치 등록, 관리자 진행률·검색·필터 | 다중 드라이브·수백만 파일 장시간 검증 |
| 시스템·프로그램·브라우저 비밀 강제 제외 | 구현됨 | 클라이언트 선제 제외와 관리자 규칙보다 우선하는 강제 제외 테스트 | 회사별 개인 폴더·인증서·메일·DB·VM 정책 결정 |
| 관리자/장치별 기능 ON/OFF | 구현됨 | 유효 정책 API, 관리자 스위치, Tauri·서비스 반영 | 정책 변경 전파 지연 실사용 측정 |
| 화이트/블랙리스트·일괄 선택 | 구현됨 | 장치 경로 규칙, 구체 경로 우선, 관리자 파일 일괄 선택 | 대규모 목록 UX 검증 |
| 최초 목록 후 승인형 순차 백업 | 구현됨 | 인벤토리 완료 후 서버 승인 대기, 승인 파일 큐 처리 | 실제 대용량 전체 백업 완료 검증 |
| 생성·수정·삭제·이동 감지 | 구현됨 | notify 기반 감시, 매니페스트 비교, SHA-256 이동 판별 | USN Journal 기반 이벤트 유실 복구는 없음 |
| 파일 안정화·잠김·재시도 | 부분 구현 | 10초 최종 수정 안정화, 업로드 실패 암호화 재시도 큐 | 잠긴 파일 장기 재시도 정책·VSS는 없음 |

| 오브젝트 저장소 | 구현됨 | Railway Bucket 스트리밍 업로드·다운로드 | 장기 내구성·지역·비용·백업 정책 운영 검증 |
| 증분·중복 방지 | 부분 구현 | 변경 파일만 처리, 동일 경로·버전 동시 캡처 방지 | 콘텐츠 전역 중복 제거 및 변경 청크만 업로드는 없음 |
| 백업 검색·버전·복원 | 구현됨 | 직원/장치/경로 검색, 버전 조회, 원본 장치 DPAPI 복원 | 다른 PC 재해복구용 조직 키 방식은 없음 |
| 관리자 조회·복원 감사 로그 | 부분 구현 | 관리자 감사 API/화면과 복원 상태 기록 | 변경 불가능한 외부 감사 저장소·강한 재인증 없음 |
| 보존기간·용량·자동 삭제 | 부분 구현 | 서버 보존 정책과 비활성 기본값 구현·테스트 | 명시적 승인 후 Railway 배포 및 실제 삭제 검증 |
| USB 연결·해제 감사 | 부분 구현 | 이동식 드라이브 연결 변화와 사용자/장치 기록 | 제조사·모델·일련번호·BitLocker 상태 수집 없음 |
| USB 파일 복사 감사 | 부분 구현 | USB 파일 생성/변경 경로·크기, `confirmedCopy: false` | 실제 원본-대상 상관관계, 파일 해시, 대량/기밀 위험도 없음 |
| 외부 네트워크 감사 | 부분 구현 | 신규 외부 ESTABLISHED TCP 주소·포트·PID 기록 | 이메일·브라우저·클라우드·메신저·공유·FTP 등 경로 분류와 전송 파일 상관관계 없음 |
| Bluetooth·인쇄·RDP 반출 | 미구현 | 해당 수집기 없음 | OS 감사 정책 또는 Endpoint DLP 연동 필요 |
| Silent Audit | 구현됨 | 직원 승인/경고 없이 백그라운드 기록, 파일 전송 확정으로 과장하지 않음 | 관리자 실시간 알림 채널은 없음 |
| CPU·디스크·업로드 제한 | 부분 구현 | 스캔 지연, 배터리 중지, 일일 업로드 한도 | CPU/디스크 실측 기반 조절, 유휴 가속, 종량제 네트워크 중지 없음 |
| 심볼릭 링크 순환 방지 | 구현됨 | 재분석 지점 미추적 테스트 | 실제 복잡한 볼륨 마운트 검증 |
| 오프라인 안전 보관 | 구현됨 | DPAPI 큐·용량 제한·서버 성공 후 삭제 | 장기간 오프라인과 디스크 부족 실사용 검증 |
| 서비스 장애가 PC 사용을 방해하지 않음 | 부분 구현 | 별도 서비스·오류 격리 구조 | 크래시 반복, 디스크 고갈, 부팅 시간 장기 검증 |
| 회사 코드 서명 | 미구현 | 설치 파일 `NotSigned` | 회사 EV/일반 코드 서명 인증서 필요 |
| 법무·노무·개인정보 운영정책 | 외부 결정 필요 | 기술 문서에 검토 항목만 기록 | 적용 장비, 고지, 법적 근거, 보존·정정·퇴사 절차 승인 |

## 다음 구현 우선순위

1. USB 제조사·모델·일련번호·BitLocker 상태 및 파일 SHA-256 메타데이터
2. 종량제 네트워크 업로드 중지와 정책 ON/OFF
3. 대량 USB 복사·압축/기밀 확장자 위험도 계산 및 관리자 표시
4. 네트워크 반출 경로별로 가능한 OS 근거를 분리하고, 확정 불가능한 영역은 Defender/Intune/DLP 연동 경계 명시
5. 장시간·오프라인·디스크 한도·서비스 재시작·재부팅 테스트 시나리오 실행
6. 명시적 운영 승인 후 Railway 최신 백엔드 배포와 백업·복원·보존정책 왕복 검증

## 완료 판정에 필요한 외부 증거

- 회사 소유 Windows PC 여러 대에서 설치, 재부팅, 로그아웃, 장시간 실행 결과
- 실제 운영 계정으로 인벤토리 → 승인 → 암호화 업로드 → 복원 전체 왕복
- Railway 보존 정책 배포 승인 및 비활성/활성 정책별 검증
- 코드 서명 인증서가 적용된 설치 파일의 유효한 Authenticode 상태
- 개인정보·노무·보존·관리자 열람 정책의 내부 승인 문서
