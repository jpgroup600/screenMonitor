## 2026-08-31 USB 반출 위험도 분석

- 장치별 관리자 정책에 `USB 반출 위험도 분석` 독립 스위치 추가, 기본값 ON이며 이전 관리자 요청이 필드를 생략해도 ON 유지
- 압축 파일(`zip`, `7z`, `rar`, `tar`, `gz`), 인증서·키·DB 계열 민감 확장자, 100MB 이상 파일을 높은 위험도로 분류
- 최근 5분 동안 USB 쓰기 50개 이상 또는 합계 1GB 이상이면 `bulk_write_window` 사유 추가
- 위험도 계산은 안정화·SHA-256 계산이 끝난 USB 쓰기 증거에 결합하고 원본 복사가 확정됐다는 표시는 하지 않음
- 서버는 `risk.level=High`인 USB 이벤트를 `High` 심각도로 승격하고 관리자는 위험 단계·사유·윈도우 통계를 상세에서 확인
- EF 마이그레이션 `AddUsbRiskDetectionPolicy`과 관리자 정책 감사 스냅샷에 새 설정 포함
- 검증: 백엔드 59개, Rust 68개, Tauri JavaScript 20개, 관리자 17개 테스트 및 양쪽 프로덕션 빌드 통과
- 실기기 제한: 연결된 USB가 없어 실제 대량 쓰기 이벤트의 서비스→Railway 왕복은 설치본 재빌드 후 검증 필요

## 2026-08-31 종량제 네트워크 백업 중지

- 장치별 관리자 정책에 `종량제 네트워크 백업 중지` 독립 스위치 추가, 기본값 ON

- 검증: 백엔드 58개, Rust 65개, Tauri JavaScript 20개, 관리자 17개 테스트 및 양쪽 프로덕션 빌드 통과
