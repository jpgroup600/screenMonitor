# Screen Monitor 프로젝트 작업 현황

> 마지막 업데이트: 2026-08-29 (Asia/Seoul)  
> 기준 브랜치: `employeeTracker`

이 문서는 프로젝트의 현재 상태, 완료 기능, 진행 순서와 다음 작업을 팀이 지속적으로 공유하기 위한 기준 문서다. 기능 추가, 설계 변경, 배포 또는 우선순위 변경이 있을 때마다 함께 갱신한다.

## 현재 단계

출퇴근·화면 모니터링의 기본 기능과 관리자 출퇴근 조회 기능을 구축한 상태다. 다음 큰 개발 단계는 Rust Windows 서비스와 전체 파일 백업 기반이다.

## 완료된 기능

### 리포 및 배포 구조

- 기존 프런트엔드와 .NET 백엔드를 단일 리포 구조로 통합
- React 관리자 대시보드, Tauri 직원 앱, .NET API 분리
- Railway API 및 PostgreSQL 운영 배포
- Railway 스크린샷 저장 볼륨 연결
- 통합 수정본을 GitHub `employeeTracker` 브랜치에서 관리

### 직원 Tauri 앱

- Electron 앱을 Tauri 2 + Rust로 이전
- 직원 로그인과 로그인 상태 유지
- 직원 배정 프로젝트 조회
- 프로젝트 업무 세션 시작·종료
- 출근 시작 및 퇴근 버튼
- 서버 출근 시각 기준 실시간 근무 타이머
- 앱 재실행 시 활성 출근 상태 복원
- 출근 후에만 프로젝트 업무 시작 가능
- 창 닫기 시 종료하지 않고 시스템 트레이로 숨김
- 트레이에서 창 복원
- Windows NSIS 설치 파일 생성

### 모니터링과 Silent Audit

- 주기적인 화면 캡처와 서버 업로드
- 관리자 요청에 따른 즉시 화면 캡처
- 활성 프로그램 시작·종료 기록
- 15초 이상 입력이 없을 때 유휴 상태 감지
- 유휴 시작·종료 구간 및 누적 유휴 시간 기록
- 직원에게 유휴·감시 경고창을 표시하지 않는 Silent Audit 정책

### 출퇴근 백엔드

- 출근, 퇴근, 현재 상태, 개인 이력 API
- 출퇴근 기록과 유휴 구간 PostgreSQL 저장
- 중복 출근 요청 멱등 처리
- 직원별 활성 출근 기록 1개 제한 DB 인덱스
- 퇴근 시 열린 유휴 구간 자동 종료 및 누적
- 관리자 출퇴근 보고서 API
- 날짜, 직원, 상태 조건 조회
- 총 기록, 근무 중, 퇴근 완료, 총 근무·유휴 시간 요약

### 관리자 대시보드

- 출퇴근 관리 메뉴 및 전용 화면
- 날짜와 근무 상태 필터
- 직원 이름·이메일 검색
- 출근 기록, 현재 근무 중, 퇴근 완료, 총 유휴 시간 요약 카드
- 직원별 출근·퇴근·근무·유휴·활동 시간 표

### 테스트 및 검증

- .NET 출퇴근 도메인 테스트
- Rust 화면 크기, 활동 전환, 인증 API, 유휴 이벤트 테스트
- Tauri 프런트 프로덕션 빌드
- 관리자 대시보드 프로덕션 빌드
- .NET API 빌드 및 EF pending-model 검사
- Railway 마이그레이션 적용 로그 확인

## 진행 예정 순서

### 1. Rust Windows 서비스

- Tauri UI와 백그라운드 서비스 분리
- Windows 부팅 시 자동 시작
- Tauri 창 또는 프로세스와 독립적으로 실행
- 로컬 IPC와 서비스 상태 보고
- 비정상 종료 및 자동 복구

### 2. 장치 등록과 백업 DB

- `Devices`
- `BackupPolicies`
- `BackupJobs`
- `Files`
- `FileVersions`
- `StorageObjects`
- `UploadParts`
- `SecurityEvents`
- `ConnectedDevices`
- `AdminAuditLogs`

### 3. 전체 드라이브 인벤토리

- 모든 고정 드라이브 탐색
- Windows 및 프로그램 폴더 제외
- 브라우저 쿠키·세션·비밀번호 저장소 제외
- 파일 경로, 크기, 수정 시각 및 SHA-256 기록
- 시스템 부하 제한과 중단·재개

### 4. 암호화 전체·증분 백업

- S3 또는 Cloudflare R2 저장소 결정
- 클라이언트 측 암호화
- 청크 업로드와 재시도
- 파일 중복 제거
- 변경 파일만 증분 백업
- 버전 관리, 삭제 보존 및 관리자 복원

### 5. USB Silent Audit

- USB 연결·해제 및 장치 정보
- BitLocker 여부
- USB로 복사된 파일 경로·크기·해시
- 대량 복사 및 압축 파일 이벤트
- 백엔드 보안 이벤트와 관리자 알림

### 6. 네트워크 반출 감사

- 네트워크 공유와 클라우드 동기화 폴더
- 브라우저 업로드, 이메일, 메신저, FTP/SFTP 검토
- 원격 데스크톱, Bluetooth, 인쇄 이벤트 검토
- 필요하면 Defender, Intune 또는 Endpoint DLP 연동

## 운영 원칙

- 직원 앱은 Silent Audit으로 동작하며 일반 이벤트 팝업을 표시하지 않는다.
- 백업과 보안 수집 범위, 목적 및 보존기간은 사전에 고지한다.
- 실제 파일은 오브젝트 스토리지에 암호화하여 저장하고 PostgreSQL에는 메타데이터만 저장한다.
- 관리자 조회·다운로드·복원은 모두 감사 로그로 기록한다.
- 새 기능은 가능한 경우 자동 테스트를 먼저 추가하고 빌드·배포 로그까지 확인한다.
- 모든 완료 작업과 다음 우선순위는 이 문서에 계속 반영한다.
