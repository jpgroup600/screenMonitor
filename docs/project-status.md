## 완료 기능

### 직원용 Tauri 앱

- 로그인과 출퇴근 상태 조회
- 출근 시작, 실시간 근무 타이머, 퇴근
- 출근 즉시 화면 캡처, 활성 프로그램, 유휴 시간 추적 자동 시작
- 직원 화면에서는 프로젝트 목록과 시간 분류 기능을 제거하고 출퇴근 흐름으로 단순화
- 직원 화면 하단에서 배정 프로젝트를 조회 전용 카드로 표시
- 프로젝트 카드는 선택할 수 없으며 출퇴근·모니터링 동작과 완전히 분리
- 직원 화면에서는 기술적인 모니터링 설명과 누적 유휴 문구를 노출하지 않고 출퇴근 정보만 간결하게 표시
- 앱과 창에 표시되는 제품명을 `출퇴근 관리 프로그램`으로 통일
- 로그인 후 미출근 상태가 계속되면 10분마다 Windows 출근 알림 표시
- 출근 처리 즉시 출근 알림 타이머 중지
- 출근 알림 타이머는 창이 트레이에 숨겨져도 지연되지 않도록 Rust 백그라운드에서 실행
- 연결된 모든 모니터를 각각 캡처해 같은 캡처 주기에 모두 업로드
- 프로젝트와 무관하게 기본 근무 세션으로 계속 모니터링
- 퇴근 시 기본/프로젝트 세션과 활성 프로그램 기록 모두 종료
- 네트워크 또는 SignalR 재연결 시 근무 세션을 임의 종료하지 않음
- 창 닫기와 `Alt+F4` 시 시스템 트레이로 숨김
- 트레이에서 창 복원
- Windows NSIS 설치 파일 생성
